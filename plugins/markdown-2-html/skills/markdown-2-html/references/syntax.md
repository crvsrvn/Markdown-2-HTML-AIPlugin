# Markdown-2-HTML 语法

正文 = CommonMark + GFM 表格 + 下列扩展。不写 HTML：`<` `>` 按普通字符显示。中文紧挨的 `**加粗**` 可以直接写，不需要加空格。

## 文件头

```yaml
---
title: 浏览器标签名        # 可省略，默认取一级标题
meta: 来源 · 日期           # 一级标题下的灰色说明，可含行内语法
toc: [2, 3, 4]              # 大纲收录的标题级别，默认 [2, 3]
numbering: false            # 关闭全部章节序号，默认开启
marks:                      # 图例记号，正文写 :m[实]
  实: {kind: ok, title: 事实：代码或一手文档可证}
css: doc.css                # 可选：页面特有样式文件（相对 .md），只用 --hs-* 令牌取色
---
```

## 标题与跳转

- `# 文档标题` 只写一个；`##` `###` `####` 自动编号为 1. / 1.1 / 1.1.1。
- `## 标题 {#s2-1}` 指定 id；不写时为 `s` + 序号（如 `s2-1`）。`{.nonum}` 不编号，`{n="4.1.1"}` 强制序号。
- `[](#s2-1)` 显示目标序号；`[文字](#s2-1)` 显示文字。目标不存在时导出报错。

## 行内

| 写法 | 效果 |
|---|---|
| `**术语**` / `==结论句==` | 加粗 / 高亮（二选一，不叠用） |
| `:ok[完成]` | 状态标签；类型 `info tip ok warn danger key muted` |
| `:m[实]` | 图例记号，含义取自文件头 `marks` |
| `:kbd[Shift]` / `:k[会议]` / `:icon[warn]` | 按键 / 灰色标签字 / 行内图标 |
| `` `RT-01` `` | 行内代码；形如编号的自动按前缀着色 |
| `[视频](url){.pill .warn}` | 链接胶囊；外链自动在新标签打开 |
| `[^1]` + `[^1]: 说明` | 脚注 |

要显示字面的 `*` `_` `[` `` ` `` `==` 时前面加 `\`。

## 代码与图

- ```` ```cpp title="Engine/…/Actor.h:10-20（节选）" ```` 代码块；超过 25 行默认折叠，`open` / `closed` 覆盖。导出时高亮。
- ```` ```plantuml caption="图注" ```` 写 PlantUML 源码，导出时用纯 JS 引擎渲染成 SVG 内联，不需要 Java。`alt="…"` 指定无障碍描述。
- ```` ```plantuml-include _style.iuml ```` 定义一次公共片段，各图里写 `!include _style.iuml` 引用。
- ```` ```mermaid ````、```` ```svg ```` 同样放进可缩放的图表视窗。
- `![说明](图片.png "图注")` 独占一段时显示为带图注的图片，`"图注"` 可省略；地址是 `.mp4` `.webm` `.ogv` `.mov` `.m4v` 时导出为页内播放器。默认大小由导出时识别图中文字字号算出，使文字接近正文字号（视频需本机有 `ffmpeg` 取帧，否则按原始尺寸）；宽度不超过正文。页面上拖右下角手柄等比缩放，双击手柄恢复默认大小。PNG / JPEG 之外的图片按原始尺寸。图片与视频按相对路径引用，不打包进 HTML，分发时连同文件一起。
- 图表视窗可拖动右下角手柄改宽高：宽度不超过正文，最小 200 × 120。

## 数据组件

````markdown
```records level=4
@会议: GDC 2026

title: 英文标题
sub: 《中文译名》
讲者: Xin Ning
links: [视频](https://…){.warn} [PPT](https://…)
desc: 简介
```
````

- 每条记录之间空一行；`@键: 值` 是本块默认值，条目缺省时补上，显示在最前。
- `title` 生成一个真正的标题（参与编号、大纲、跳转），id 缺省为“上级标题 id-序号”，可用 `id:` 指定。
- `sub` 加粗副标题；`links` 显示为链接胶囊；`desc` 简介；`note` 灰色说明（如“无简介”）；其他键显示为“键 值”。

````markdown
```heatmap plain=2 bins=2,5,9,15 total=合计 row-link=#y{row} cell-link=#y{row}-{n} tip="{row} · {col}：{v} 场" legend="色块深浅 = 分享数" note="点击跳转"
年份,合计,其中渲染向,类别A,类别B
2026,107,18,8,
合计,107,18,8,
```
````

- 正文只写 CSV；空格子表示 0。`plain`：标签列之后不着色的列数；`bins`：前 4 档的上限（第 5 档为更大）；`total`：合计行的标签。
- `row-link` / `cell-link` / `tip` 是模板：`{row}` 行标签、`{col}` 列名、`{v}` 数值、`{n}` 本行第几个非空着色格。链接目标不存在时导出报错。
